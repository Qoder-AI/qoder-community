## 使用场景

- 审查工作报告/总结中是否存在形式主义（重过程轻结果、重痕迹轻成效）
- 诊断管理制度/方案是否存在教条主义（照搬照抄、不本土化、体系"两张皮"）
- 检查会议纪要中的责任稀释问题（层层签字无人负责、"小陈背锅"模式）
- 评估述职/自评中的指标游戏（拍脑袋目标）和传声筒现象
- 审查个人安全行动计划的形式与实效（照搬照抄/拍照留痕/监督失灵）
- 分析培训记录中的学用脱节问题（学时达标但能力没上去）
- 诊断 JSA/HAZOP 风险辨识是否模板化、应急演练是否表演化
- 检查整改报告是否闭环（"已整改"有无实际改善证据链）

## 示例

输入一段工作报告文本：

```
本月共组织安全培训4场，覆盖全员326人次，培训后考试平均分92.5分，安全意识显著提升。
```

Skill 自动输出诊断报告：

| 字段 | 内容 |
|------|------|
| 原文片段 | 「培训后考试平均分92.5分，安全意识显著提升」 |
| 三风类型 | 教条主义（主）+ 形式主义（次） |
| 要害 | 僵 + 虚 |
| 置信度 | 🟡 中 |
| 应该的标准 | 培训效果以"行为改变 + 事故率/隐患率下降"衡量；按"教练赛帮"重组培训形态 |
| 整改建议 | (1) 考试外增加现场实操考核；(2) 跟踪培训后30天行为观察数据；(3) 把"安全意识显著提升"替换为可衡量的行为指标（违章数下降率、隐患自报率） |

## 核心能力

- **四维信号扫描**：80+ 条语言(L)/行为(B)/文档(D)/数据(N)红旗信号，逐条扫描输入文本
- **五大分析镜片**：脱离实际度、形式替代内容度、教条照搬度、责任担当度、有效性检验度
- **三级置信度**：🟢高/🟡中/🔴低，低置信信号不进入正文，避免过度诊断
- **应该的标准对照**：三大板块（主价值链/平台/职能）+ 七大领域 + 安全20模块
- **根因追溯**：连续五问（Five Whys）+ 五看三定/5W1H/五步法工具绑定
- **防过诊四闸**：必要形式校验、最小阈值、非三风路由、输入不足处理

## 注意事项

- 本 Skill 基于某化工企业化工/制造业组织文化语境蒸馏，互联网/金融/政府等行业需适当调整
- AI 看不到一线现场，最终判断需使用者结合对具体业务的了解
- 任何分析工具都无法替代"迈开两脚，到工作范围的各部分各地方去走走"的实地调查
- 反三风是长期任务，一次性、运动式使用本 Skill 本身就是形式主义
- 不应对号入座搞扩大化——反三风不是搞斗争，目的是完善制度、优化流程、提升能力
