## 使用场景

- 对用户提供的 CSV、Excel、SPSS 或 Stata 数据，完成常见研究和报告分析。
- 先检查变量类型，再选择已支持的任务，在本地运行并解释统计结果与适用边界。
- 先完整渲染脚本输出中面向用户的 Markdown 结果表，再解释结果。

## 已支持的任务

公开版 v0.2.5 文档列出以下 22 类常见任务：

1. 数据概览
2. 频数与比例
3. 多选题比例
4. 词频
5. 常模对照
6. 正态性检查
7. Pearson 或 Spearman 相关
8. 独立样本 t 检验
9. 配对样本 t 检验
10. 卡方独立性检验
11. 单因素方差分析
12. Mann–Whitney 或 Kruskal–Wallis 非参数比较
13. 线性回归
14. 二元 Logistic 回归
15. 有序 Logistic 回归
16. Cronbach α 信度
17. 探索性因子分析（EFA，含 KMO 与 Bartlett 结果）
18. 主成分分析（PCA）
19. 聚类
20. ROC/AUC 分析
21. 决策树评估
22. 两组样本量估计

## 示例

安装公开技能：

```bash
npx skills add jessepwj/ChatSPSS --skill chatspss
```

安装后可以这样提问：

> 请检查这份问卷数据，比较两组的结果，完整展示结果表，并说明检验假设和限制。

## 注意事项

- 结果展示要求完整渲染分析脚本输出的所有面向用户的 Markdown 表格；保留表头、顺序、数值、精度、显著性标记、标题和注释，然后再作解释。
- CFA/SEM、中介或调节、纵向与面板模型、空间分析及高级机器学习等进阶请求，会被识别并说明不属于当前 22 类已实现任务。公开包提供按需读取的范围说明，但不声称本地分析脚本能运行这些方法。
- 公开包通过本地脚本和 Python 依赖运行。本目录记录不表示已在 Qoder 中实跑、不表示获得 Qoder 背书，也不表示它是 Qoder 官方技能。
